# Projektprofil

**Status:** Pending Project Init – Pflichtprofil. Der Agent befüllt diese Datei bei Project Init aus geprüften Projektfakten und bestätigten Entscheidungen; bis dahin keine geltende Projektrichtlinie.

Diese Datei beschreibt dauerhafte Fakten und Grenzen eines konkreten Projekts. Sie ordnet Ziel, Nutzer, Architektur, Daten, Schnittstellen, Technologie und Betriebsrahmen ein. Sie hält den Startweg und den Einstieg zum Quality Gate fest; einzelne Checks stehen in der Gate-Konfiguration. Sie wird bei Projektänderungen gepflegt. Universelle Arbeitsregeln gehören nicht hierher.
