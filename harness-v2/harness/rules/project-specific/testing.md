# Testregeln

**Status:** Pending Project Init – optionale Projektrichtlinie; Inhalt für das neue Projekt noch nicht definiert.

Diese Datei beschreibt projektspezifische Konventionen für Testaufbau, Testdaten und Testwerkzeuge. Sie ordnet Tests den Specs und den Akzeptanzkriterien des Projekts zu. Sie schützt bei Bedarf echte Daten und legt fest, wie Tests isoliert und reproduzierbar ausgeführt werden. Sie wird nur angelegt oder geladen, wenn das Projekt eigene Testregeln benötigt. Universelle Qualitätsprinzipien verbleiben in `../universal/quality.md`.
